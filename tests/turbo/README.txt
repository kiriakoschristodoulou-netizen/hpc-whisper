HPC Whisper Turbo Test 1.0
by Kyriakos Christodoulou

This measures how much faster the link can go, in two modes: the silent
mode (high tones you cannot hear) and a fast mode that uses the whole
audible range (1-19 kHz) and sounds like a loud hiss. It plays new kinds of
sound through your handheld and lets the phone record them. Every sound
carries known data, so the recording shows exactly how much arrived intact.

WHAT IS IN THIS FOLDER
  turbotest.exe   the test program for the handheld
  turbotest.wav   the test sound (the program plays it; keep it next to it)
  phone-test.wav  a sound for the phone to play (microphone test only)
  README.txt      this file

SETUP
  Copy turbotest.exe and turbotest.wav into one folder on the handheld
  (for example My Documents). Start turbotest.exe.
  The program sets the volume to full while it plays and puts it back after.

TEST 1: PLAY TEST (the important one, 25 seconds)
  1. On the phone, open HPC Whisper. Under Diagnostics, tap
     "Record 30 seconds".
  2. Within 3 seconds, press P on the handheld.
  3. Hold the phone about 30 cm from the handheld, the same way as when you
     type. Keep the room as it normally is.
  4. Listen. The screen shows which part is playing. Note any part you can
     hear (a hiss, a click, a whine) in the silent parts. "LOUD" is meant
     to find the limit, so hearing it is useful information too.
     The last 8 seconds ("Fast mode") are meant to be heard: a sweep and a
     loud hiss. Keep the phone where it is until the end.
  5. When the phone says "Recorded", it saves a copy in Downloads as
     HPC-Whisper-recording-(date).wav. Send that file as a file (not through
     WhatsApp, which removes the high sounds).

TEST 2: MICROPHONE TEST (30 seconds, for the phone-to-handheld direction)
  1. Copy phone-test.wav onto the phone.
  2. Press M on the handheld. It starts recording.
  3. Right away, play phone-test.wav on the phone at a moderate volume, its speaker
     facing the handheld, about 30 cm away. The sound is audible: a
     sweep, some beeps, a short buzz and a hiss.
  4. When it finishes, copy mictest.wav and turbotest.txt from the
     handheld's folder and send them.

TEST 3: SPEED TEST (a few seconds)
  Press S. It checks whether the processor can make and read the new
  sound fast enough. The answer is on screen and in turbotest.txt.

Space stops a test. Q closes the program.

WHAT TO SEND BACK
  HPC-Whisper-recording-(date).wav (from the phone), mictest.wav and turbotest.txt
  (from the handheld), and which parts you could hear.
